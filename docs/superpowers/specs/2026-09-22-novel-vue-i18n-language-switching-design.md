# 小说 H5 Vue I18n 与语言切换设计

## 背景

免费小说系统以英文作为唯一原文，后端已经支持运营人员选择目标语言、异步生成完整译本并原子发布。H5 当前使用自定义字典和语言状态管理，并把尚未发布的语言展示为禁用项。

本次改造需要让运营人员一次生成全部八种目标语言，让用户只看到真正可阅读的语言，并使用 Vue 官方生态的 `vue-i18n` 管理 H5 界面文案。小说正文仍使用后端提前生成并保存的译文，不在用户浏览器内实时翻译。

## 目标

- 运营后台的八种目标语言在进入小说编辑页时默认全部勾选。
- 运营人员继续点击独立的“生成翻译”按钮，一次创建全部八种语言任务。
- H5 语言菜单不再显示灰色、锁定或禁用语言，只显示英文和已经完整发布且启用的译文。
- 使用 `vue-i18n` 的 Composition API 管理九种 H5 界面语言。
- 用户切换语言时，界面文案和小说数据在同一次语言状态变化中更新。
- 新用户首次访问时根据 IP 国家选择默认语言；用户手动选择后长期记住，并优先于后续 IP 判断。

## 非目标

- 不在 H5 端调用翻译接口。
- 不在用户选择语言时临时生成小说译文。
- 不移除运营人员的“生成翻译”确认步骤。
- 不改变英文原文、译本版本、完整发布或原文更新后保留旧译本的规则。
- 不增加新的用户账号、登录或付费能力。

## 运营后台流程

小说编辑页加载时，`translationSelection` 初始化为全部八个目标语言代码：`id`、`ja`、`ko`、`ms`、`pt`、`fil`、`th`、`vi`。

运营人员仍可以取消个别勾选，但默认操作是直接点击一次“生成翻译”。按钮提交当前勾选数组，后端继续按语言建立相互独立的异步任务。每个语言只有在标题、摘要、作者、分类和全部启用章节都翻译成功后才发布。

任务创建成功后把选择恢复为全部八种语言，方便原文更新后再次批量生成。任务状态、进度、失败原因和前台展示开关保持现有行为。

## H5 国际化架构

### Vue I18n

H5 安装 `vue-i18n`，使用 `createI18n` 创建全局实例，并设置：

- `legacy: false`
- `fallbackLocale: "en"`
- `messages`: 现有九套完整界面字典

组件通过 Composition API 的全局作用域读取 `t` 和响应式 `locale`。现有自定义 `translate` 实现移除，语言持久化、路由同步和可用语言过滤保留为一个轻量 locale controller；它只负责业务状态，不重复实现 Vue I18n 的翻译能力。

### 可用语言

服务端启动数据继续返回 `available_locales`。该列表只包含：

- `en`
- 当前投放链接绑定小说已经完整发布并启用的译文语言

H5 菜单只渲染 `available_locales` 中的语言。因此未生成、生成失败、被运营停用或尚未完整发布的语言不会出现，也不存在禁用状态。

当运营人员完成八种语言翻译后，菜单显示英文加八种译文，共九种语言。

### 语言切换

用户点击语言后执行一个统一的切换过程：

1. 校验目标语言位于 `available_locales`。
2. 更新 Vue I18n 全局 `locale`，界面文字立即变化。
3. 写入 `novel_lang` Cookie 和 `localStorage`，保存一年。
4. 使用 Vue Router 更新当前 URL 的 `lang` 参数，不刷新整个文档。
5. 首页、搜索、列表、小说详情和章节监听全局 locale，重新请求携带 `lang` 的数据。
6. 使用现有请求版本门避免旧语言的慢响应覆盖新语言页面。

小说内容由后端本地化查询返回。某一本非入口推荐小说没有对应译文时，继续按现有规则回退该书英文内容；投放链接绑定小说的目标语言一定来自其已发布列表，因此入口小说不会出现界面已切换但正文未翻译的情况。

## 首次访问与 IP 默认语言

语言优先级保持为：

1. URL 查询参数 `lang`
2. 已保存的 `novel_lang` Cookie 或本地选择
3. IP 国家映射
4. 英文

新用户没有保存语言时，服务端使用现有 GeoIP 国家结果选择：

- 印度尼西亚：`id`
- 日本：`ja`
- 韩国：`ko`
- 马来西亚、文莱：`ms`
- 巴西、葡萄牙及现有葡语国家映射：`pt`
- 菲律宾：`fil`
- 泰国：`th`
- 越南：`vi`
- 其他国家：`en`

IP 对应语言只有位于当前入口小说的 `available_locales` 时才生效，否则回退英文。用户手动选择后，Cookie 优先于后续 IP 判断。

## 数据与接口

不新增数据库迁移和公共接口。

继续使用：

- 启动数据：`locale`、`available_locales`
- 公共查询参数：`lang`
- 翻译管理接口：生成任务、状态查询、译本启停
- 后端本地化查询和英文回退

H5 只调整语言状态管理和组件接入方式。运营后台只调整复选框默认值以及任务创建成功后的选择保留。

## 异常与降级

- `vue-i18n` 缺少某个界面键时回退英文。
- URL 或 Cookie 包含不支持、未发布或已停用语言时，服务端和 H5 都回退英文。
- 翻译任务部分失败时，成功发布的语言可以使用，失败语言不出现在 H5 菜单。
- 快速连续切换时，只有最后一次语言请求可以更新页面。
- GeoIP 数据库不可用、IP 无法识别或国家不在映射中时使用英文。

## 测试与验收

### 运营后台

- 编辑小说时八种语言默认全部选中。
- 取消部分语言后只提交当前选择。
- 创建任务成功后八种语言仍保持默认选择。
- 原有任务轮询、状态、失败和启停功能不回归。

### H5

- Vue I18n 以 Composition API 模式安装，九套字典完整。
- 菜单只包含英文和 `available_locales`，不渲染锁定项。
- 切换语言同步更新界面、URL、Cookie、localStorage 和小说请求。
- 快速切换不会被旧响应覆盖。
- 首页、搜索、列表、详情、章节和目录文案都跟随语言变化。
- IP 国家映射、URL、记忆选择和英文回退优先级正确。
- 首页与阅读页移动端菜单布局正常。
