# 小说多语言翻译设计

## 目标

免费小说 H5 以运营录入的英文小说为唯一原文，通过接口盒子翻译接口按运营人员勾选的语言生成并保存译本。访客首次访问时根据 IP 国家选择语言，也可以从页面入口手动切换并记住选择。

这不是实时翻译。访客请求只读取已经完整发布的译本；翻译服务故障、任务处理中或译本过期时继续提供英文或旧译本，不阻断阅读、短链归因、Meta 事件和停留时间统计。

## 已确认业务边界

- 运营后台始终录入英文原文，接口盒子源语种固定为 `ytype=1`。
- 运营人员在小说编辑页勾选目标语言，点击独立的“生成翻译”按钮后才创建任务。
- 支持且只支持：印度尼西亚语、日语、韩语、马来语、葡萄牙语、菲律宾语、泰语、越南语。
- 未勾选语言不创建任务、不调用翻译接口。
- 每种语言全部内容成功后才发布；不得公开半成品译文。
- 英文内容修改后，旧译文继续在线并显示“原文已更新”；新译文完成后原子替换旧版本。
- H5 提供语言切换入口，用户选择保存一年并覆盖 IP 推断。
- 不增加用户登录、付费或账号权限。
- 不创建或推送 Git 提交。

## 语言定义

| Locale | 名称 | APIHZ `etype` | 主要 IP 国家 |
| --- | --- | ---: | --- |
| `en` | English | 不调用 | 其他国家及回退 |
| `id` | Bahasa Indonesia | 24 | ID |
| `ja` | 日本語 | 27 | JP |
| `ko` | 한국어 | 28 | KR |
| `ms` | Bahasa Melayu | 31 | MY、BN |
| `pt` | Português | 35 | BR、PT、AO、MZ、CV、GW、ST |
| `fil` | Filipino | 43 | PH |
| `th` | ไทย | 44 | TH |
| `vi` | Tiếng Việt | 48 | VN |

语言解析顺序：有效 `?lang=`、语言 Cookie、本次入口 IP 国家、英文。只有当前绑定小说已发布对应译本时才选择该语言，否则回退英文。非法语言值不写 Cookie。

## 翻译服务

后端使用 `POST https://cn.apihz.cn/api/zici/fanyiapihz.php`，以 UTF-8 表单提交：

- `id`：服务器环境变量 `APIHZ_TRANSLATION_ID`
- `key`：服务器环境变量 `APIHZ_TRANSLATION_KEY`
- `words`：待翻译文本
- `ytype=1`
- `etype`：目标语言编号
- `htype=1`

ID 和 KEY 只存在于后端配置，不返回浏览器、不写数据库、不进入日志。单次文本按 UTF-8 字节数控制在 5000 内，正常块尽量保持在约 500 个字符。Markdown 以段落块拆分，保留空行；代码块和纯 URL 不翻译。

网络错误、非 2xx、JSON 错误、`code != 200` 或空译文均视为失败。单个内容项最多尝试三次，使用短退避。任务失败后保留明细，运营人员可以重新生成该语言。

## 数据模型

### 原文修订号

`novels.source_revision bigint not null default 1`。修改小说标题、作者、分类、简介、章节标题、正文、章节启停或章节增删时递增；封面、推荐、排序与上下架不改变翻译修订号。

### `novel_translation_versions`

每次对一种语言生成一个不可变版本：

- `id`, `novel_id`, `locale`, `source_revision`
- 翻译后的 `title`, `author`, `category`, `excerpt`
- `status`: `queued|running|failed|published|superseded`
- `total_items`, `completed_items`, `error_message`
- `created_at`, `started_at`, `finished_at`, `published_at`

同一小说和语言最多一个 `queued/running` 版本，最多一个 `published` 版本。新版本完成后，在事务内把旧发布版本改为 `superseded`，再发布新版本。

### `novel_chapter_translations`

- `version_id`, `chapter_id`, `chapter_number`
- 翻译后的 `title`, `body_markdown`
- 唯一键 `(version_id, chapter_id)`

任务开始时记录原文修订号；发布前再次比较。原文已变化时任务标记失败且不得替换旧译本。

## 后台接口与任务执行

- `GET /api/v1/novels/:id/translations`：返回八种语言的发布状态、进度和是否过期。
- `POST /api/v1/novels/:id/translations`：请求体 `{"locales":["ja","ko"]}`，只接受目标语言且去重。
- `PATCH /api/v1/novels/:id/translations/:locale/status`：启用或停用已发布语言；停用不删除内容。

任务由应用内有限并发工作器执行。应用启动时恢复 `queued` 任务，并把遗留 `running` 任务重新排队。默认两个工作器，避免把第三方接口和数据库打满。缺少 APIHZ 配置时生成接口返回明确错误，不创建任务。

后台小说编辑页新增多语言卡片。复选框只表示本次需要生成的语言，不会因取消勾选而删除旧译文。状态表展示未生成、排队中、翻译中、已发布、原文已更新、失败与停用；生成按钮提交当前选择，任务进行时定时刷新。

## 公开接口与 H5

小说公开 API 接受 `lang` 查询参数。仓储查询仅使用该小说当前启用且已发布的译本；不存在时返回英文。搜索在选择的译文字段中匹配，相关作品与首页列表分别按每部小说可用性回退英文。

入口启动数据新增：

- `locale`：后端根据 URL、Cookie、IP 与可用译本解析出的语言。
- `available_locales`：英文和当前绑定小说已启用的已发布译本。

H5 内置九套固定界面文案，不调用翻译接口。语言切换更新 `lang` 查询参数、Cookie 和 localStorage，并重新获取当前路由数据，不重新加载 `/novel/:code` 文档，因此不新增入口访问。页面的 `lang` 属性和标题同步更新。

## 错误与一致性

- 翻译服务不可用：任务失败，英文和旧译文继续可读。
- 原文翻译中被修改：任务不得发布，状态提示原文已更新。
- 部分章节失败：整个语言不发布，保留失败信息供重试。
- 小说或章节删除：后续新版本不包含删除内容；已公开旧译本随英文小说/章节的公开状态一起隐藏。
- IP 无法识别、代理配置错误或国家无映射：英文。
- Cookie 中语言无效或该小说不支持：英文，不报错。

## 测试与完成标准

- 数据迁移验证修订号、版本唯一性、级联关系和状态约束。
- APIHZ 客户端验证 POST 参数、语种映射、UTF-8 分块、三次重试、密钥不泄漏和错误返回。
- 翻译任务验证只生成勾选语言、完整发布、原文变化拒绝发布、旧译本保留与原子替换。
- 管理接口和页面验证复选框、生成、进度、失败重试、过期与停用状态。
- 公开接口验证语言查询、译文搜索、逐作品回退英文、非法语言和短码兼容。
- H5 验证 IP 初始语言、手动切换、持久化、可用语言限制以及切换不新增访问。
- 运行后端、运营后台、小说 H5 的测试和构建，并回归普通短链、语音小说、Meta 和小说投放统计。
