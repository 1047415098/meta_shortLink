# 文字小说投放链接入口章节绑定实施计划

## 目标

- 每条新建的文字小说投放链接必须绑定一个启用中的入口章节。
- 绑定章节的 `/novel/{code}` 直接进入该章节；历史未绑定链接继续进入小说简介页。
- 首次正常 GET 访问后，小说、入口章节、广告平台与 Pixel 同时锁定。
- 每次访问冻结入口章节 ID、编号与标题，后续章节改名或改号不改变历史统计。
- TikTok `StartReading` 以该次访问冻结的入口章节为准，不再硬编码第一章。

## 数据与后端

1. 新增迁移：`short_links.entry_chapter_id`，以及 `click_events` 的入口章节快照字段；迁移不回填旧链接。
2. 创建和访问前编辑时验证章节属于绑定小说、已启用且未删除。
3. 已有正常访问后拒绝修改小说或入口章节；入口章节停用/删除时入口返回 410，恢复后自动恢复。
4. 投放链接 API、启动数据与统计明细返回入口章节字段。
5. 旧链接的章节字段保持为空，不自动改写历史配置。

## 运营后台

1. 创建/编辑投放链接时加载所选小说章节并提供入口章节下拉框。
2. 新链接默认选择第一条可读章节；小说变化时清空旧章节并重新加载。
3. 首次访问后同时锁定小说与入口章节。
4. 列表显示入口章节；旧链接显示“简介页（兼容旧链接）”。

## 小说 H5

1. 启动数据存在入口章节时，从根地址直接切换到章节阅读路由。
2. 仅有小说 slug 的旧链接继续进入简介页。
3. `StartReading` 上报实际入口章节，章节内后续导航不新增入口访问或改变归因。

## 验证

- 数据迁移、章节归属/状态校验、首次访问锁定与历史快照。
- 旧链接兼容、绑定章节 410/恢复、直接章节路由。
- 后台章节加载、默认选择、切换小说清理与锁定状态。
- TikTok `StartReading` 的章节校验、幂等与错误票据。
- 后端完整测试、管理后台与 H5 测试/构建、Docker 本地健康检查。
