# TimeSpent 实施计划

1. 新增数据库迁移：code 阈值、访问冻结阈值和一次性上报时间。
2. 扩展短链接 Gin 模型、校验、持久化与后台编辑表单。
3. 访问创建时冻结阈值，并在两个公开页面 bootstrap 中注入阈值和去重事件 ID。
4. 新增经过签名、同源、surface、GET 访问和服务端时长校验的 TimeSpent 接口。
5. 扩展 Meta 服务，生成 `TimeSpent` 自定义 Pixel/CAPI 事件。
6. 为短链接落地页和小说站增加仅可见时累计的计时器、固定显示组件和一次性上报。
7. 补充 Go/JS 测试，构建三个前端，执行数据库迁移并完成浏览器回归。
