# Vue projects and Go modules implementation plan

Goal: preserve existing business behavior while separating admin and landing Vue applications and modularizing Go.
Architecture: frontend routes /admin/*; independent landing routes /:code; one Go server records visitor requests and embeds escaped bootstrap JSON in landing HTML. Existing API/contact endpoints and database remain compatible.
Tech stack: Vue3 JavaScript SFC (template, script setup, style scoped), Vue Router, Element Plus only in admin, Go/Gin, PostgreSQL.
Spec: user-approved design in this conversation (two sibling frontend/landing projects, shared backend; no page-local components folders).
Constraints: no Git commits/push; do not alter existing link settings or reset production DB. Keep compression/cache and cookie configuration. Preserve no-store for HTML/API and request logging scope.
