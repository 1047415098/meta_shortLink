# English landing page reference

Reference: https://peplyra.com/products (viewed 2026-09-09).

The layout adapts the reference navy/white/teal palette, laboratory banner, product-card presentation and research-only positioning. Six catalog entries are featured: Tirzepatide, Retatrutide, Semaglutide, AOD9604, Cagrilintide and Tesamorelin. Cards link to the corresponding reference product pages. Prices, inventory quantities, therapeutic claims and checkout functionality are not reproduced.

Assets in landing/public/landing-assets/images are copies of the reference page's rendered product thumbnails, laboratory banner and brand mark, retrieved from the browser's loaded assets. Their original rights remain with their owners. This reference is the basis for the user-requested adaptation.

All public landing text, timer text and visitor errors are English. Admin labels remain Chinese. Existing per-link countdown values and WhatsApp targets are preserved. Main text remains editable through the existing link form; product cards are maintained in the landing template.

Legacy copies under frontend/public/assets/landing are retained only for previously opened pages using /assets/landing URLs. New landing pages use the independent landing project.
